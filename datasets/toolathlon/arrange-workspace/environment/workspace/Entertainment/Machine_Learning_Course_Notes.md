## 第一章 机器学习概述

### 1.1 什么是机器学习
机器学习是人工智能的一个分支，通过算法让计算机从数据中学习，而不需要显式编程。

### 1.2 机器学习的类型
- **监督学习**：有标签数据，如分类、回归
- **无监督学习**：无标签数据，如聚类、降维
- **强化学习**：通过与环境交互学习

### 1.3 机器学习的基本流程
1. 数据收集
2. 数据预处理
3. 特征工程
4. 模型选择
5. 模型训练
6. 模型评估
7. 模型部署

## 第二章 线性回归

### 2.1 线性回归原理
线性回归假设目标变量与特征之间存在线性关系：
y = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

### 2.2 损失函数
均方误差（MSE）：
L = (1/n) * Σ(y_pred - y_true)²

### 2.3 梯度下降
通过迭代更新参数来最小化损失函数：
w = w - α * ∇L(w)

## 第三章 逻辑回归

### 3.1 逻辑回归原理
逻辑回归用于二分类问题，使用sigmoid函数：
σ(z) = 1 / (1 + e^(-z))

### 3.2 损失函数
交叉熵损失：
L = -[y * log(y_pred) + (1-y) * log(1-y_pred)]

## 第四章 决策树

### 4.1 决策树原理
决策树通过一系列if-then规则进行分类或回归。

### 4.2 信息增益
信息增益用于选择最佳分裂特征：
IG = H(S) - Σ(|Sᵥ|/|S|) * H(Sᵥ)

### 4.3 过拟合问题
- 预剪枝：限制树的深度
- 后剪枝：剪掉不必要的分支

## 第五章 支持向量机

### 5.1 SVM原理
SVM寻找最优超平面来分离不同类别的数据。

### 5.2 核函数
- 线性核：K(x,y) = x^T y
- 多项式核：K(x,y) = (γx^T y + r)^d
- RBF核：K(x,y) = exp(-γ||x-y||²)

## 第六章 神经网络

### 6.1 神经元模型
神经元接收输入，通过激活函数输出：
y = f(Σwᵢxᵢ + b)

### 6.2 激活函数
- ReLU：f(x) = max(0, x)
- Sigmoid：f(x) = 1/(1+e^(-x))
- Tanh：f(x) = (e^x - e^(-x))/(e^x + e^(-x))

### 6.3 反向传播
通过链式法则计算梯度，更新网络参数。

## 第七章 聚类算法

### 7.1 K-means聚类
1. 随机选择K个中心点
2. 将每个点分配给最近的中心
3. 重新计算中心点
4. 重复步骤2-3直到收敛

### 7.2 层次聚类
- 凝聚聚类：自底向上
- 分裂聚类：自顶向下

## 第八章 模型评估

### 8.1 分类评估指标
- 准确率：Accuracy = (TP + TN) / (TP + TN + FP + FN)
- 精确率：Precision = TP / (TP + FP)
- 召回率：Recall = TP / (TP + FN)
- F1分数：F1 = 2 * (Precision * Recall) / (Precision + Recall)

### 8.2 回归评估指标
- 均方误差：MSE
- 均方根误差：RMSE
- 平均绝对误差：MAE
- R²分数
